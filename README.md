# British-Airways-Dashboard
## Here's my first Tableau Dashboard! It looks a British Airways reviews and ratings accross the world. I've included my scource data too. 

This Dashboard looks at the ratings from a number of different metrics and elegantly presents the data and stats in an beautiful, interactive dashboard. 
The target audience would be company directors enabling them to make thier own analysis. 
# Skills I used to create this were: 
- Joins
- Creation of Parameters & Calculated Fields
- Exploratory and Explanatory Analysis
- Descriptive Statistics
- Tableau visualisation techniques

# Method: 
I wanted to see where British airways performed best across a range of areas. The first thing I did was create the map and in order to create the 'Pick a Metric' I had to first create the Parameter and then implement a Calculated Field to make the map change to present the chosen metric. I then created the summary at the top to give an easy, overall view of the ratings. This was fairly straightforward, I just used some basic visualisation skills. Then I wanted to show the ratings by aircraft but I first had to make an 'other' group as I had dozens of aircraft types many of which had less then 10 revies so I grouped all aircraft with < 50 reviews. I created a coloured bar chart to match the map and one with the count of reviews. Finally I created a line chart to show the average rating over time which was also to see the months/ years where they performed well and where the didn't. All charts were interactive with the 'Pick a Metric' which I achieved by adding the pre-established filters to all worksheets.
